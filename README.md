# Kinoshka

Настольное приложение для просмотра видео с YouTube, фильмов и сериалов с RuTube
и прослушивания музыки — онлайн и офлайн, с персональными рекомендациями,
локальными профилями и встроенным VPN для обхода блокировок.

Разработано **Budin's industries**.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

pip install -r requirements.txt

python main.py                  # окно приложения
python main.py --web            # то же самое в браузере (отладка)
python main.py -v               # подробные логи
```

Дополнительно нужен **ffmpeg** в PATH — без него нельзя склеивать видео
высокого качества с аудиодорожкой и конвертировать музыку в mp3.

## VPN для YouTube

В России YouTube не открывается напрямую, поэтому VPN встроен в приложение.

1. Откройте **Настройки → VPN для YouTube**.
2. Нажмите **«Импортировать .conf»** и выберите файлы WireGuard от Portal wg.
3. Включите переключатель **«Использовать VPN»** и нажмите **«Подключить»**.
4. Кнопка **«Проверить соединение»** покажет, доступен ли YouTube и ваш внешний IP.

Как это работает:

* конфигурации копируются в `%APPDATA%\Kinoshka\vpn` — **не в репозиторий**,
  потому что внутри приватные ключи (`vpn/` и `*.conf` в `.gitignore`);
* перед каждым запросом к YouTube вызывается `VpnManager.ensure_connected()`;
* если конкретный узел заблокирован, `YouTubeProvider` автоматически пробует
  следующую конфигурацию (`vpn.rotate()`);
* для системного туннеля нужен установленный клиент
  [WireGuard](https://www.wireguard.com/install/) и права администратора;
* если ставить WireGuard нельзя — впишите HTTP/SOCKS-прокси в настройках,
  он будет использован и запросами, и yt-dlp.

### Где лежат пользовательские данные

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\Kinoshka` |
| Linux | `~/.local/share/kinoshka` |
| macOS | `~/Library/Application Support/Kinoshka` |

Там же база `kinoshka.db`, `settings.json`, `vpn/`, `downloads/`, `logs/`.
Переменная `KINOSHKA_DATA_DIR` переопределяет каталог — удобно для тестов
и портативного режима.

## Как работают рекомендации

Профиль вкусов — это набор пар «категория → вес» (0.1 … 5.0):

* **просмотр**: вес растёт тем сильнее, чем больше досмотрено
  (досмотрел до конца +0.30, бросил в начале +0.05);
* **поиск**: поисковая фраза добавляется как интерес (+0.25), совпавшие
  категории усиливаются (+0.15);
* **затухание**: интересы, которые месяц не подтверждались, слабеют на 10%
  за сеанс — лента не застревает на прошлогодних увлечениях.

Движок не ходит в сеть. Он отдаёт `build_query_seeds()` — список запросов из
топовых интересов и недавних поисков, по ним провайдер собирает ленту, а затем
`personalize()` пересортировывает результат и убирает уже досмотренное.

Учёт просмотра идёт по событиям позиции плеера, а не по таймеру: пауза
не засчитывается, перемотка вперёд не накручивает время.

## Сборка установщика (Windows)

```bash
pip install pyinstaller
# и Inno Setup 6: https://jrsoftware.org/isdl.php

python build_installer.py
```

Результат: `installer_output\Kinoshka-Setup-0.2.0.exe`.

Другие режимы:

```bash
python build_installer.py --onefile       # один .exe, без установщика
python build_installer.py --no-installer  # только сборка
python build_installer.py --console       # оставить консоль для отладки
```

Положите `ffmpeg.exe` в корень проекта перед сборкой — он попадёт внутрь
дистрибутива, и пользователю не придётся ставить его отдельно.
Иконка берётся из `assets/icon.ico`, если файл есть.

Установщик намеренно **не удаляет** `%APPDATA%\Kinoshka` при деинсталляции:
профили, история и скачанное переживают переустановку.

## Тесты

```bash
KINOSHKA_DATA_DIR=/tmp/kinoshka-test python tests/smoke_ui.py
```

Тест строит все экраны и компоненты со заглушкой страницы. Он не требует
браузера и сети и ловит несовместимости с API Flet (переименованные параметры
и события) — именно так были найдены отличия Flet 0.86: `PopupMenuItem.content`
вместо `text`, `Dropdown.on_select` вместо `on_change`, асинхронный
`FilePicker.pick_files()`, события `Video.on_load` / `on_complete`.

## Планы на следующий этап

1. **RuTube** — провайдер по образцу `youtube.py` (yt-dlp его поддерживает).
2. **Кинопоиск** — парсер рейтингов, постеров, жанров и новинок.
3. **Запасной поиск по интернету**, когда фильма нет на RuTube.
4. **ИИ-поиск** — OpenAI-совместимый API (ключ и модель уже есть в настройках).
5. **Музыка** — аудиоплеер с очередью и плейлистами.
6. **Джарвис** — ассистент по управлению приложением.
